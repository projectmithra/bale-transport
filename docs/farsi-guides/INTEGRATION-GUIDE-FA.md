# راهنمای اتصال اپلیکیشن‌ها به Bale Transport

این راهنما نحوه اتصال اپلیکیشن‌های رایج به تونل Bale Transport را توضیح می‌دهد. در همه روش‌ها، ابتدا باینری مستقل `bale-transport` باید روی کامپیوتر اجرا شود.

## پیش‌نیاز

باینری مستقل را اجرا کنید:

```bash
./bale-transport -worker wss://your-worker.example.com/w
```

پس از اجرا، یک پروکسی محلی روی `127.0.0.1:1984` فعال می‌شود.

سپس SingBox یا هسته پروکسی دلخواه را با اتصال به `127.0.0.1:1984` تنظیم کنید (مطابق نمونه در راهنمای کلاینت). پروکسی نهایی روی پورت `2080` در دسترس خواهد بود.

## Hiddify (اندروید)

Hiddify یک کلاینت متن‌باز اندروید بر پایه SingBox است.

### روش ۱: تنظیم دستی

۱. Hiddify را باز کنید
۲. به بخش **پروفایل‌ها** بروید
۳. **افزودن پروفایل جدید** را بزنید
۴. نوع **VLESS** را انتخاب کنید
۵. مقادیر زیر را وارد کنید:

| فیلد | مقدار |
|------|-------|
| آدرس | `IP-کامپیوتر` |
| پورت | `1984` |
| UUID | UUID سرور شما |
| امنیت | `none` |
| ترنسپورت | `tcp` |

۶. ذخیره کنید و متصل شوید.

### روش ۲: لینک اشتراک

لینک زیر را در Hiddify وارد کنید (مقادیر را جایگزین کنید):

```
vless://UUID-شما@IP-کامپیوتر:1984?security=none&type=tcp#Bale-Transport
```

## V2RayNG (اندروید)

۱. V2RayNG را باز کنید
۲. علامت **+** را بزنید
۳. **تنظیم دستی [VLESS]** را انتخاب کنید
۴. مقادیر زیر را وارد کنید:

| فیلد | مقدار |
|------|-------|
| نام | `Bale Transport` |
| آدرس | `IP-کامپیوتر` |
| پورت | `1984` |
| id (UUID) | UUID سرور شما |
| امنیت (encryption) | `none` |
| ترنسپورت (network) | `tcp` |
| امنیت (tls) | `none` |

۵. ذخیره کنید و متصل شوید.

## V2Box (iOS)

۱. V2Box را باز کنید
۲. به بخش **Servers** بروید
۳. **Add Server Manually** را بزنید
۴. نوع **VLESS** را انتخاب کنید
۵. مقادیر زیر را وارد کنید:

| فیلد | مقدار |
|------|-------|
| Address | `IP-کامپیوتر` |
| Port | `1984` |
| UUID | UUID سرور شما |
| Encryption | `none` |
| Network | `tcp` |
| TLS | `off` |

۶. ذخیره کنید و متصل شوید.

## Nekobox (اندروید)

۱. Nekobox را باز کنید
۲. **+** را بزنید و **VLESS** را انتخاب کنید
۳. مقادیر مشابه V2RayNG را وارد کنید
۴. در بخش **Transport**، نوع `tcp` را انتخاب کنید
۵. ذخیره و اتصال

## تست اتصال

بعد از اتصال، مرورگر گوشی را باز کنید و به یکی از آدرس‌های زیر بروید:

- `https://www.google.com`
- `https://www.bbc.com`

اگر صفحه بارگذاری شد، اتصال برقرار است.

برای تست IP:

- به `https://whatismyipaddress.com` بروید
- IP نمایش‌داده‌شده باید IP سرور شما باشد (نه IP ایران)

## ساختار کلی اتصال

```
گوشی (Hiddify / V2RayNG / V2Box)
  │ VLESS روی TCP
  ▼
SingBox / هسته پروکسی (پورت 2080)
  │ VLESS روی TCP
  ▼
bale-transport (پورت 1984)
  │ WebSocket با پروتوباف بله
  ▼
Cloudflare Worker
  │ WebSocket
  ▼
bale-unwrapper (سرور، پورت 80)
  │ داده خام
  ▼
Xray (پورت 8443) → اینترنت آزاد
```

## نکات مهم

**مصرف باتری:** اگر از V2Box یا Hiddify به عنوان VPN محلی استفاده می‌کنید، باتری بیشتری مصرف می‌شود. برای مرورگر، فقط تنظیم پروکسی WiFi کافی است.

**سرعت:** سرعت به فاصله شما تا سرور Cloudflare و سرور مقصد بستگی دارد. سرورهای اروپایی (آلمان، هلند) معمولا بهترین عملکرد را برای کاربران ایرانی دارند.

**قطعی:** اگر اتصال قطع شد، بررسی کنید که باینری `bale-transport` هنوز اجرا باشد. در صورت قطع، دوباره اجرا کنید.

**امنیت:** UUID را با کسی به اشتراک نگذارید. هر کاربر باید UUID مخصوص به خود داشته باشد.
